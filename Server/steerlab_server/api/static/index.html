RepE reader (faithful)

Concept data → reader artifact → optional steering variant. A reader is a fitted measurement instrument (task template + LAT token position + PCA training normalization + held-out accuracy) — not "positive/negative text → vector". The "LAT paired direction (RepE-inspired)" recipe above is a separate, direction-only comparison. Readers are per-model, per-substrate; they fit on this server's loaded model as a durable job.

No template-listing API yet: these are the two registry ids committed under prompts/templates/. The server re-reads and validates the template file at fit time, so an unknown or edited id fails loudly instead of fitting silently.

Cross-vector geometry (cosine)

Select vectors and a layer, then compute the pairwise cosine matrix. Distinct concepts should not collapse into one direction.

Gemma Scope — SAE cross-check

Rank an independently-trained SAE's features by cosine against a concept vector (Gemma 3 only). Import a feature's decoder direction as a steering vector.

J-Space — Jacobian lens

Reads what the model is poised to verbalize, and derives steering directions from a lens. Server-only and Gemma-only: imported lens artifacts are PyTorch/HF-native and activations do not transfer across substrates, so there is deliberately no local/MLX equivalent — everything here runs on whichever server this page is connected to. Scores are estimated verbalizable representations, never access to beliefs or reasoning.
