# Design a multi-agent study

Declare interaction structure and controls before casting agents.

Ask about roles, shared materials, private information, turn order, visibility/routing, stopping rules and measured outcomes. Specify baseline, each-solo and combined-treatment comparisons where they answer the question; do not assume a composition sweep is the research design.

Use authoring study multiAgent for the shared interview and study-pack skeleton. Semantic panel JSON describes roles, materials, turns, routing, contracts and outcomes. Model settings and agent artifacts belong in the study's casting. Task prompts do not substitute for a panel transcript.

Publish with panel import after checking source bytes. Inspect the panel and agents, then panel compile with the reviewed study and input digests and every seat explicit (null for baseline). Compilation changes studyKind and studyType to multi-agent, including when the source draft was a concept study. Review that intent before applying it; duplicate a draft if the original design must remain available.

Use design expand to preview distinct permutations or baseline/each-solo/all-treated batch rows. Review the rows before design batch, then preserve successful publications if a later row fails. The study authorship interfaces share these owners; Python executes panel turns on its supported runner.

Outputs are compiled pinned scenarios and transcripts with declared outcome measurements. More agents do not imply independent observations. State the unit of analysis, interference assumptions, visibility policy and transcript-judging plan.

## Coworker author prompt

Help author the inputs for this method. First restate the researcher-approved construct, comparison, model/revision, input roles and proposed claim. List unresolved scientific choices as questions; do not choose them silently. Use the schema and public operations above and the selected authoring prompt. Return proposed files separately from an audit describing split independence, labels, nuisance balance, applicability and missing facts. Do not execute, invent pins, or overwrite evidence.

## Independent review prompt

Review the proposed inputs without assuming the author is correct. Check the declared method, schema, labels, split overlap, source/identity pins, baseline and controls, rendering/sampling settings and whether the requested claim follows from the planned measurements. Separate mechanical checks from scientific judgment. Name each blocker and its repair; passing a parser is not scientific validation.
