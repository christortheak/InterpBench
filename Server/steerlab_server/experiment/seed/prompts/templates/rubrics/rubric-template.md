Compare the two responses against these criteria. Score only what the
criteria name — ignore style, length, and eloquence unless a criterion
makes them relevant.

1. Task fidelity: which response more completely does what the task
   prompt asked (answers the question asked, honors stated constraints,
   addresses every part of a multi-part prompt)?
2. Substantive difference: do the two responses reach different
   conclusions or recommendations, or do they differ only in wording?
   A wording-only difference is a tie on this criterion.
3. Internal consistency: which response's stated conclusion actually
   follows from the reasons it gives? A response whose reasoning and
   conclusion disagree loses this criterion.
4. Groundedness: which response stays within the information given in
   the task prompt, without inventing facts the prompt does not
   contain?

Weigh the criteria in the order listed. Prefer "tie" when the evidence
is genuinely indistinguishable.
