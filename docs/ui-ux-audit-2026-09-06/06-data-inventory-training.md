## Findings

- **[BUG]** `JSpacePanelSection.swift:38,45` — server-only gate `service.cluster.client == nil` — can never be true. `ExperimentKit/ClusterConnectionStore.swift:734-741` builds a `ClusterClient` whenever `connectionProfile` parses, and `serverURL` (L681-682) falls back to `defaultServerURL = "http://127.0.0.1:8080"` (L134), so `client` is always non-nil. The designed "No server connection … J-Space has no local equivalent by design" notice (L77-92) is dead code; on a Local (MLX) workspace the panel renders the full server surface (Model picker, Acquire, Import, "Token → direction", `JLensSupportSection`, `JLensTraceSection`), `.task { await refresh() }` (L44, L290-307) fires at 127.0.0.1:8080 and the user gets `"could not read the server's lens catalog: <URLError text>"` instead. Acquire/Import/Show token options then stay disabled only as a side effect of `selectedModelID` being empty, with no explanation. Gate on the active workspace — `case .server = service.cluster.activeWorkspace` (what `FineTuningPanel.beginServerTraining` uses, `ExperimentKit/FineTuningPanel.swift:951`) or `service.cluster.computeTarget == .server` as `FineTuningPanelView.swift:23,208` does. (Extra item (e).)
- **[BUG]** `DatasetCreationSheet.swift:699-718` — `commit(replacing:)` — sets `isApplying = true`, then calls the synchronous `plan.apply(...)` on the main actor with `defer { isApplying = false }`. No run-loop turn happens between set and reset, so the `ProgressView` at L600-602 and the `.disabled(isApplying)` gates (L512, L599) never render; a large import (the file copy + parse) blocks the UI with no indicator and no re-entry protection that is actually observable. Run `apply` off the main actor (`Task.detached`, as `DatasetInventoryModel.refresh` does at `ExperimentKit/DatasetInventory.swift:848`) or remove the dead spinner.
- **[BUG]** `DatasetCreationSheet.swift:104-110` — `.fileImporter` completion — `guard let slot, case .success(let url) = result else { return }` silently drops the `.failure` case; a chooser error yields no feedback (extra item (c): file-chooser feedback). Set `failure = error.localizedDescription`.
- **[BUG]** `ModelRevisionRow.swift:52-53` — `revisionText` — `@State` seeded in `onAppear` and re-synced only on `manifest.name` change. If the same draft's revision changes through another surface (pack apply, import-prompts, a re-read), the field keeps the old text while `disabled(revisionText == storedRevision)` (L40) now compares against the new value, so "Set" lights up and would write the stale string back. Add `.onChange(of: manifest.modelRevision)`.
- **[BUG]** `TabularImportSheet.swift:65-69` — `choose()` — `try? panel.management.reviewStudy(named:)` swallows the thrown reason and reports `"Select and review a draft before importing a table."` even when a draft IS selected and review failed for another reason (malformed manifest, missing file). - **[BUG]** `JSpacePanelSection.swift:227-228, 341-347` — "Derive direction on server" — gated on `selectedLensID != nil && selectedToken != nil`, but sends `modelID: selectedModelID` from the Model picker, which is independent of the selected lens's `fit?.modelID` (L133-134). ## Notes on strengths

- The New Dataset flow previews every destination path, collision, and verb (create / add-to / replace) before writing, and the replace path is behind a `.destructive` alert whose message spells out the freeze-verification consequence (`DatasetCreationSheet.swift:111-116, 687-697`).
- Every Inventory route only navigates and selects — no build starts from a click (`SectionContainers.swift:76-144`), and the derive gating plus its destination sentence come from one model (`DatasetDerivation`), so the view decides nothing.
- OptVec renders energies only as energy/null pairs, cosines only beside null percentiles, carries the engine's screen-grade firewall verbatim, and stamps the J-space "unqualified" rider (`OptVecPanelView.swift:408-415, 476-480, 644-652, 690-699`).
- Adapter Training's server route parks the normalized plan in a confirmation sheet with cancel/default shortcuts and hashes the confirmed plan (`FineTuningPanelView.swift:299-304, 728-770`); the base-model pickers keep an uninstalled selection visible but selection-disabled rather than dropping it (L314-329).
- The layout note about the macOS 27 split-view minimum-height hazard is honored throughout this cluster: every frame minimum is a constant.
