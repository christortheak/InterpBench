The Dataset Builder picker lists `RecipeFamily.allCases` unfiltered, while the Vector Type picker hides `isServerOnly` families in Local (`:269-273`). ## Notes on strengths

- Destructive concept deletion is confirmed with a precise scope statement (what is deleted, what is kept: `:412-424`), and server→local fetch confirms before overwriting (`:425-445`).
- Every engine refusal (reading position, rendering, template, contrast, designated reference, server declaration, norm backfill) is rendered as selectable orange text next to the control it gates, and the build failure lands in a dismissable banner plus the Activity log (`:3020-3037`).
- Clipboard failure has a real fallback: the prompt is still recorded under "Last copied prompt" (`:1994-2003`).
- Help text on the server-side actions is unusually honest about WHERE data is read from and WHERE the artifact lands (`:2952-2960`, `:921-924`), and "Use" buttons explain their own disabled state (`:779-782`, `:2844-2847`).
- Readiness `detail` strings carry repair actions, and blockers get a one-click "Create from template" that also pins the file (`DataReadinessSection.swift:212-231`).
